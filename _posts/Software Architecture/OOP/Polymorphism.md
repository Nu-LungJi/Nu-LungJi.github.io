"다형성"은 동일한 인터페이스에서 다양한 동작을 할 수 있도록 하는 OOP의 핵심 특성.  
다형성은 같은 이름의 함수가 다른 동작을 수행하지만, 그 기능을 일관되게 사용할 수 있다는 점에서 기능을 확장하거나 변경에 도움을 주고, “코드의 **재사용성**을 높이기 위한” 장점을 가지고 있다. 또한, 코드의 간결성, 유지 보수성을 높이고, OOP의 특성 중 하나인 “추상화”를 더 강화시킨다.

**조건 :**
	- 부모와 자식이 **“상속관계”여야 한다.
	- 부모와 자식 클래스 안에, **“완전히 일치”**하는 형태의 함수가 존재해야 한다.  
    (반환형, 함수명, 매개변수(자료형, 개수), const까지 다 동일)
	- 부모의 멤버 함수 앞에 **“virtual”** 키워드를 붙여준다.
	- **“부모” + “포인터”** 를 자료형으로 사용해야 하고, 자식을 대상으로 참조한다.

- **정적 바인딩 :** 컴파일 타임(프로그램 실행 시)에, 어떤 함수가 호출될지 '결정'되는 것.  
    포인터 변수의 클래스 타입**(클래스 자료형)**에 따라 그 타입에 맞는 함수를 호출.
- **동적 바인딩 :** 런타임(프로그램이 실행하고 있는 중에)에, 어떤 함수가 호출될지 '결정'되는 것. 
    그렇기에 함수를 탐색하는 시간으로 인해, 정적 바인딩보다 속도가 느리다.  
    (보통 virtual 키워드가 붙은 가상 함수에서 수행.)

→ **다형성의 구현 :**

다형성을 사용하는 것부터 “자식의 것을 사용하겠다.” 라는 암묵적인 룰이 결정 되기에, 부모의 함수를 부를 일도, 필요도 없는 것이다. (그렇다고 못 부르거나, 아예 안쓰는 것은 아니다.)  
그렇기에 보통, 부모에서는 선언만 해놓고 (선언부), 구체적인 수행은 자식에서 정의한다. (구현부)

**-> 오버로딩 :** 같은 이름의 함수를 “매개변수의 개수/자료형”에 따라 그에 맞는 함수를 호출하는 것. 기능을 동일한 이름으로 “캡슐화” 시킬 수 있고, 코드의 가독성을 향상시킨다. (반환형은 바뀌어도 오버로딩X)

→ **오버라이딩 : 자식의 공통적인 요소(함수)들을 다형성을 이용해서 사용하는 것.**

**일반 정의** : initialize(), Update() 함수같이 대다수의 클래스가 가지고 있는 함수라고 한다면,  
같은 형식의 이름으로 호출한다 했을 때, 관리하는 입장에서 편하게 사용이 가능한 장점을 가진다.

**코드 정의 :** 포인터는 **부모**, 참조 대상은 **자식**, 함수를 가상화 시켜서 호출하는 것.

→ **오버라이딩의 은닉 :** 자식과 부모 사이에서 우선권을 가진 객체가 있다면, 우선권이 없는 객체는 가려진다. (은닉)

→ **RTTI :** 런타임에 어떤 타입인지 알려주는 것.
→ **typeid :** 현재 참조 객체/포인터 타입을 알려주는

→ **다운 캐스팅 :** 
	- 캐스팅 연산자 : ~ [ 연산자<형 변환 자료형>(형 변환 대상) ]
- **static_cast :** **'컴파일 타임'** 에 캐스팅을 수행하는 연산자. (C 스타일 캐스팅과 흡사) (논리적인 형 변환만 수행 = 비논리적인 형 변환 지원X) 논리 판단 기준 : 클래스의 상속 관계

- **dynamic_cast :** '**런타임**'에 캐스팅을 수행하는 연산자. 오로지 클래스의 다운캐스팅을 위해서만 사용한다. 클래스 상속 관계, 부모 클래스에 가상 함수가 1개 이상 존재하는 조건에서 수행.

→ 속도는 static_cast가 dynamic_cast보다 빠르다.(런타임에 논리성을 검사하기 때문에.)
→ 안정성이 확보 된다면, dynamic_cast에서 static_cast로 바꾸는 것이 더 좋다.(속도 차원에서)

- **const_cast :** const의 성격을 벗겨내는 캐스팅 연산자. (포인터 변수, 레퍼런스 변수만 가능) 개발 단계가 아닌, 서비스 단계에서 임시적으로 사용한다. (대부분 사용 X)
- **reinterpret_cast :** const 포인터를 제외한 모든 포인터의 형 변환을 허용. (비논리적인 경우도 허용한다.) (대부분 사용 X)

**다만, 어떤 종류의 캐스팅이던 안전하지 않다는 것을 알아두자.**
