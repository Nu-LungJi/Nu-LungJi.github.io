# Advanced Sort - 비교(Compare) 기반 정렬

## Merge Sort

→ **정렬법 :** 원소 갯수가 1개 이하가 되도록 반복적으로 분할하고, 다시 반복적으로 합치는 동시에, 원소 값들을 비교하여 정렬하는 방식.

**※ Top-Down 방식 - 재귀 형태**
→ **과정 :** 
1. vector의 가운데 기준으로 2개 구간으로 1차 분할, 분할 된 구간에서 다시 가운데 기준으로 분할, 구간에 있는 원소가 1개 이하가 될 때까지 과정을 반복한다. 
2. 분할 된 원소를 합치면서 값을 비교하고, 임시 배열에 저장해 두었다가, 정렬된 하나의 구간으로 병합한다. 이 과정을 반복하여 모든 원소를 합친다.

**※ Bottom-Up 방식 - 반복 형태**
→ **과정 :** 
1. vector를 처음에 1칸에 대해서 값을 비교하고 정렬을 하면서 순회한다. 정렬은 빈 벡터를 2칸 (1칸 + 1칸) 만들어서 작은 것부터 빈 벡터에 채워, 다시 원래 벡터의 2칸에 순서대로 넣어준다. (정렬됨.)
2. 이것을 반복하는데, 칸 수를 x2씩 늘려 작은 단위에서 큰 단위로 늘려 정렬하는 방식으로 진행한다. ex. 2칸 비교 - 빈 벡터 4칸을 이용하여 병합 수행 -> 4칸 -> 8칸 ... 순으로 병합한다.

→ **효율성 :** 데이터 갯수가 많은, '대용량 외부 정렬'같은 경우에도 빠른 정렬로 해결할 수 있고, 원소들의 기존 순서를 유지함. 다만, 공간 복잡도에서 효율이 떨어진다. 연결 리스트 정렬에 특히 유리하다.
→ **그 외 :** 분할 정복 방식(Divide & Conquer) 채택, 안정적인 정렬 보장, 일정 성능 보장
→ **C++ :** C++에서는 `std::stable_sort`를 제공하는데, 병합 정렬을 기반으로 만들어진 정렬 함수이다.

! 위 두 방식은 구현에만 차이가 있지, 성능은 차이가 거의 없다.

> [!note]- Merge Sort (Top-Down)
> **병합 정렬 구현** 
> ``` cpp
>void Merge(std::vector<int>& _vec, int _Left, int _Center, int _Right) { 
>    int LeftIndex = _Left;  
>    int RightIndex = _Center;  
>    int ArrayIndex = _Left;  
>    
>    std::vector<int> SortedArray(_Right);  
>    
>    while (LeftIndex < _Center && RightIndex < _Right)  {
>        SortedArray[ArrayIndex++] = _vec[LeftIndex] <= _vec[RightIndex] ? _vec[LeftIndex++] : _vec[RightIndex++];  
>    }
>    
>    int LastIndex = LeftIndex >= _Center ? RightIndex : LeftIndex;  
>    
>    while (ArrayIndex < _Right) { SortedArray[ArrayIndex++] = _vec[LastIndex++]; }
>    
>    for (int i = _Left; i < _Right; ++i) { _vec[i] = SortedArray[i]; }  
>}
>  
>void Divide(std::vector<int>& _vec, int _Left, int _Right)  {  
>    if (_Right - _Left <= 1) return ;  
>    int Center = (_Left + _Right) / 2;  
>     
>    Divide(_vec, _Left, Center);  
>    Divide(_vec, Center, _Right);  
>    Merge(_vec, _Left, Center, _Right);  
>}  
>
>void MergeSort(std::vector<int>& _vec) {  
>    Divide(_vec, 0, static_cast<int>(_vec.size()));  
>}
>```

> [!note]- Merge Sort (Bottom-Up)
> **병합 정렬 구현** 
> ``` cpp
> void Merge(std::vector\<int>& _vec, int _Left, int _Center, int _Right) { 
>    int LeftIndex = _Left;  
>    int RightIndex = _Center;  
>    int ArrayIndex = _Left;  
>    
>    std::vector<int> SortedArray(_Right);  
>
>    while (LeftIndex < _Center && RightIndex < _Right)  {
>        SortedArray[ArrayIndex++] = _vec[LeftIndex] <= _vec[RightIndex] ? _vec[LeftIndex++] : _vec[RightIndex++];  
>    }
>    
>    int LastIndex = LeftIndex >= _Center ? RightIndex : LeftIndex;  
>    
>    while (ArrayIndex < _Right) { SortedArray[ArrayIndex++] = _vec[LastIndex++]; }
>    
>    for (int i = _Left; i < _Right; ++i) { _vec[i] = SortedArray[i]; }  
>}
>
>void BottomUpSort(std::vector<int>& _vec) {  
>    int Size = static_cast<int>(_vec.size());  
>    for (int Width = 1; Width < Size; Width *= 2)  {  
>       for (int Left = 0; Left < Size; Left += Width * 2) {  
> 	       int Center = std::min(Left + Width, Size);  
>            int Right = std::min(Left + 2 * Width, Size);  
>            
>            Merge(_vec, Left, Center, Right);  
>        }  
>    }  
>}
>``` 
## Quick Sort

→ **정렬법 :** 하나의 데이터 리스트를 비균등한 크기로 분할하고, 
→ **과정 :** 
1. 데이터 리스트에서 하나의 원소를 Pivot으로 선택한다. 
2. Pivot을 기준으로 좌측에는 피벗보다 작은 원소들, 우측에는 Pivot보다 큰 원소들로 이동시켜 정렬시킨다.
3. 분할된 두 리스트도 재귀호출로 최소 단위까지 정렬시켜, 전체 정렬을 완료시킨다.

→ **효율성 :** 배열같은 연속 메모리를 정렬하면, **캐시 효율**이 좋아 왠만한 정렬보다 빠르게 나오는 경우가 있다. 메모리가 한정적인 상황이라면, 제자리 정렬을 생각하며 사용이 가능하다. 평균 O(N log N)의 평균적으로도 빠른 성능을 보인다. 하지만, Pivot 선택에 따라, 최악의 경우 **O(N²)**까지 성능이 저하될 수 있다.
→ **그 외 :** 불안정한 정렬, 제자리 정렬(In-Place Sorting), 캐시 친화적인 정렬 방법. 정렬 알고리즘 중에서 빠른 속도/고성능

> [!note]- Quick Sort
> **퀵 정렬 구현** 
>``` cpp
>void QuickSort(std::vector<int>& _vec, int _Left, int _Right) {
>    if (_Right - _Left <= 1) return ;
>    int Pivot = _vec[_Left + (_Right - _Left - 1) / 2];
>    int i = _Left - 1;
>    int j = _Right;
>  
>    while (true) {  
>        do { ++i; } while (_vec[i] < Pivot);
>        do { --j; } while (_vec[j] > Pivot);
>        
>        if (i >= j) break;
>        
>        std::swap(_vec[i], _vec[j]);
>    }  
>    QuickSort(_vec, _Left, j + 1);
>    QuickSort(_vec, j + 1, _Right);
>}
>```
## Heap Sort

→ **정렬법 :** 완전 이진 트리 자료구조의 '힙(Heap) 트리'를 통해 구성하여 정렬하는 방법. (내림차순 = 최대 힙, 오름차순 = 최소 힙)
→ **과정 :** 
1. 주워진 원소들을 배열에 나열하고, 처음부터 삽입 순으로 '힙 트리'를 구성한다.
2. 오름차순 기준으로, '힙 생성 알고리즘'(Heapify)를 적용하여, 최소 힙을 구성한다.
3. [루트 노드]와 [최종 자식 노드] 와 자리를 변경하여 다시 '힙 생성 알고리즘'을 적용한다.
   (이 때, 자리가 변경된 루트 노드를 제외하고, 나머지 데이터 (N-1)개에 대해서만 적용.)
4. 이 과정을 반복한다.

→ **효율성 :** 시간 복잡도와 공간 복잡도의 이점을 통해 대용량 데이터 처리에 유용한 정렬. 다만, **구현도가 높고**, 실제 힙 구조가 연속된 노드로 이뤄진 것이 아니기 때문에, 힙 정렬을 할 때, 전체 데이터를 많이 넘나드는 방식이라 C++에서 **캐시 효율이 많이 떨어지게 된다**.
→ **그 외 :** 불안정한 정렬, 제자리 정렬(In-Place Sorting), 시간 복잡도 전부 O(N log N), 공간 복잡도 O(1) - 안정적인 성능.

> [!note]- Heap Sort
> **힙 정렬 구현** 
>``` cpp
>void Heapify(std::vector<int>& _vec, int _size, int _index) {  
>    int Largest = _index;  
>    int Left = 2 * _index + 1;  
>    int Right = 2 * _index + 2; 
>     
>    if (Left < _size && _vec[Left] > _vec[Largest])   Largest = Left;  
>    if (Right < _size && _vec[Right] > _vec[Largest]) Largest = Right;  
>    if (Largest == _index) return;  
>    
>    std::swap(_vec[Largest], _vec[_index]);  
>    Heapify(_vec, _size, Largest);  
>}  
>  
>void HeapSort(std::vector<int>& _vec) {  
>    int Size = static_cast<int>(_vec.size());  
>    for (int i = Size / 2 - 1; i >= 0; --i) {  
>       Heapify(_vec, Size, i);  
>    }  
>    for (int i = Size - 1; i > 0; --i) {  
>       std::swap(_vec[0], _vec[i]);  
>       Heapify(_vec, i, 0);  
>    }  
>}
>```
## Shell Sort

→ **정렬법 :** 삽입 정렬의 빠른 속도를 기안하여, 전체를 대상으로 정렬하기 전에, 간격(Gap)으로 정렬할 원소들을 나누어 정렬을 수행한 뒤, 간격을 줄이면서 1이 될 때까지 정렬을 수행한다.
(간격은 홀수가 좋고, 줄일 때, 2 씩 줄인다. ex. 5 > 3 > 1)
→ **과정 :**
1. 주어진 원소 배열을 두고, 간격(K) = (원소 갯수) / 2를 구한다.
2. 배열 Arr[n * K]에 대한 원소를 추출하여 정렬한다. 예를 들어, 전체 원소 갯수가 21개 이면, K는 10일 것이고, 추출된 원소는 Arr[0], Arr[10], Arr[20]이다. 이 세 원소를 정렬한다.
3. Arr[n * K + 1]에 대해 정렬, Arr[n * K + 2]에 대해 정렬, Arr[n * K + 3] ... Arr[n * K + (K - 1)]에 대해 원소들을 정렬시킨다.
4. 이후에 간격을 K = K / 2 시켜 간격을 줄이고, 위 과정을 반복 하면서, K가 1이 될 때까지 간격을 줄여간다.

→ **효율성 :** 간단한 구현, 삽입 정렬보다 빠른 최선/평균 성능, 소/중규모의 데이터 처리에 빠른 성능. 제자리 정렬. 다만, Gap 수열에 의해 성능이 결정되는 불확실한 성능 예측 존재. 그리고 불안정 정렬.

> [!note]- Shell Sort
> **셸 정렬 구현** 
>``` cpp
>void Shell_InsertionSort(std::vector<int>& _vec, int _first, int _last, int _Gap) {  
>    int j, Key;  
>  
>    for(int i = _first + _Gap; i <= _last; i += _Gap) {  
>        Key = _vec[i];  
>        for(j = i-_Gap; j >= _first && _vec[j] > Key; j -= _Gap) {  
>            _vec[j + _Gap] = _vec[j]; >        
>        }  
>        _vec[j + _Gap] = Key;  
>    }  
>}  
>  
>void ShellSort(std::vector<int>& _vec) {  
>    int Size = static_cast<int>(_vec.size());  
>       for (int Gap = Size % 2 == 0 ? Size / 2 + 1 : Size / 2; Gap > 0; Gap /= 2) { 
>        Gap = Gap % 2 == 0 ? Gap + 1 : Gap;  
>        for (int i = 0; i < Gap; ++i) {  
>            Shell_InsertionSort(_vec, i, Size - 1, Gap);  
>        }  
>    }  
>}
>```

# Advanced Sort - 비-비교(Non-Compare) 기반 정렬

## Radix Sort

→ **정렬법 :** 낮은 자리 수의 값에서 부터 가장 높은 자리 수까지의 값을 정렬하는 방식.
→ **과정 :** 
1. 각 데이터들의 1의 자릿수를 참조해서 0 - 9 버킷에 각각 분류한다. 예를 들어 데이터가 43, 22, 56, 10, 4, 83, 72 이 있다면, [0번] - 10 / [1번] - X / [2번] - 22, 72 / [3번] - 43, 83 / [4번] - 4 / [5번] - X / [6번] - 56 / ... /[9번] - X 로 분할하고, 0번 버킷부터 순서대로 배열에 나열한다. -> { 10, 22, 72, 43, 83, 4, 56 } (버킷에서는 들어간 순서대로 정렬한다. 83, 43이 있다면 3번 버킷에서는 83, 43 그대로 넣는 방식.)
2. 다음으로 10의 자릿수를 참조해서 작업을 수행한다. 
3. 자릿수를 올리면서 분류하여 정렬 시킨다.

→ **효율성 :** 비-비교 정렬로 빠른 정렬 시간, Counting Sort의 비효율성 개선하는 정렬. 하지만, 자릿수가 존재하는 원소만 정렬이 가능 (정수, 문자열), 추가적인 메모리 공간 필요.

> [!note]- Radix Sort(Only Positive Numb)
> **기수 정렬 구현** (모든 원소가 양수인 전제 하)
>``` cpp
>int GetMaxNumber(std::vector<int>& _vec)  
>{  
>    int MaxNumber = 0;  
>    for (const auto& Element : _vec) {  
>        MaxNumber = MaxNumber < Element ? Element : MaxNumber;  
>    }  
>    return MaxNumber; 
>}  
>  
>void CountSort(std::vector<int>& _vec, const int _size, int _exp) {  
>    std::vector<int> Output(_size, 0);  
>    int Bucket[10] = { 0 };  
>    for (int i = 0; i < _size; i++) {  
> 	   Bucket[(_vec[i] / _exp) % 10]++;    
> 	   // 각 자릿 수 확인해서 버킷에 들어가는 원소 수 증가  
>    }  
>    for (int i = 1; i < 10; i++) {  
>        Bucket[i] += Bucket[i - 1];         
>        // 인덱스 매핑을 위한 원소 수 누적합 계산 : 각 버킷에서는 최대 인덱스가 들어감  
>        // 0 이하의 개수 = 2개 > 숫자 0들은 정렬된 배열의 0~1번 인덱스에 들어가야 함.  
>        // 2 이하의 개수 = 5개 > 숫자 2들은 정렬된 배열의 2~4번 인덱스에 들어가야 함.  
>    }  
>    for (int i = _size - 1; i >= 0; --i) {   
>    // 안정 정렬을 위해, 배치를 뒤에서부터 시작.  
>        int& CurrentBucket = Bucket[(_vec[i] / _exp) % 10];  
>        int OutputIndex = CurrentBucket - 1;  
>        Output[OutputIndex] = _vec[i];  
>        CurrentBucket--;  
>    }  
>    for (int i = 0; i < _size; i++){  
>        _vec[i] = Output[i];                // 정렬된 결과 이동  
>    }  
>}  
>  
>void RadixSort(std::vector<int>& _vec, int _size) {  
>    int MaxLength = GetMaxNumber(_vec);  
>    for (int exp = 1; MaxLength / exp > 0; exp *= 10) {  
>        CountSort(_vec, _size, exp);  
>        // 1의 자리부터 최대 자릿수까지 반복
>    }  
>}
>```

> [!note]- Radix Sort
> **기수 정렬 구현**

>    for (int i = ElementSize - 1; i >= 0; --i) {   
>    // 안정 정렬을 위해, 배치를 뒤에서부터 시작.  
>        int& CurrentBucket = Bucket[(_vec[i] / _exp) % 10];  
>        int OutputIndex = CurrentBucket - 1;  
>        Output[OutputIndex] = _vec[i];  
>        CurrentBucket--;  
>    }  
>    for (int i = 0; i < ElementSize; i++){  
>        _vec[i] = Output[i];                // 정렬된 결과 이동  
>    }  
>}  
>  
>void AppendOffset(std::vector<int>& _vec, int _offset) {  
>    for (auto& Element : _vec) {  
>        Element += _offset;  
>    }  
>}  
>  
>void RadixSort(std::vector<int>& _vec) {  
>    int MinNumber = GetMinNumber(_vec);  
>    AppendOffset(_vec, -MinNumber);  
>    int MaxLength = GetMaxNumber(_vec);  
>    for (int exp = 1; MaxLength / exp > 0; exp *= 10) {  
>        CountSort(_vec, exp);  
>    }  
>    AppendOffset(_vec, MinNumber);  
>}
>```
## Counting Sort

→ **정렬법 :** 주어진 원소 데이터들 중에서 중복되는 값이 몇 개 있는지 갯수를 세고, 값이 작은 것부터 차례대로 갯수만큼 나열하는 비-비교 정렬법.
→ **과정 :**
1. 데이터들의 최댓값을 구하고, 최댓값 만큼 크기의 배열을 만든다. (값은 0 초기화)
2. 모든 원소들을 세면서, 각 배열 인덱스에 맞게 수를 증가 시킨다.
3. 배열의 누적합을 구하여, 인덱스의 범위를 구한다. ARR[i-1] = 시작 인덱스, ARR[i] = 마지막 인덱스 + 1
4. 출력 배열에 나열 시켜, 정렬한다.
→ **효율성 :** 데이터들의 최댓값에 따라 성능이 좌우된다. 최댓값이 작을 수록 선형 시간,

> [!note]- Counting Sort
> **계수 정렬 구현** 
>``` cpp
>void CountingSort(std::vector<int>& _vec) {  
>    int ElementSize = static_cast<int>(_vec.size());  
>    
>    int MinNumber = GetMinNumber(_vec);  
>    AppendOffset(_vec, -MinNumber);  
>    
>    int MaxNumber = GetMaxNumber(_vec);  
>    
>    std::vector<int> Array(MaxNumber + 1, 0);  
>    std::vector<int> Output(ElementSize, 0);  
>    
>    for (const auto& Element : _vec)    Array[Element]++;  
>  
>    for (int i = 1; i < MaxNumber + 1;++i) {  
>        Array[i] += Array[i - 1];  
>    }  
>    
>    for (int i = ElementSize - 1; i >= 0;--i) {  
>        Output[Array[_vec[i]] - 1] = _vec[i];  
>        Array[_vec[i]]--;  
>    }  
>    
>    for (int i = 0; i < ElementSize; i++){  
>        _vec[i] = Output[i];                // 정렬된 결과 이동  
>    }  
>    
>    AppendOffset(_vec, MinNumber);  
>}
>```
## Bucket Sort

→ **정렬법 :** 주어진 원소 데이터를 균등한 범위로 나눠서, 원소들을 각각의 버킷으로 분할한 뒤, 버킷 내부에서 정렬하여, 다시 나열하는 정렬법.
→ **과정 :** <실수 데이터 정렬>
1. 2차원 배열로 Bucket을 생성. (Bucket 수는 조절할 수 있도록 매개변수화)
2. 현재 생성된 Bucket에 고르게 분포될 수 있도록 (원소 * 전체 Bucket 수)로 Bucket Index를 결정. 
3. Bucket 내부에서 정렬을 하고(삽입 정렬 or 계수 정렬), 원래 배열에 값 채워 넣어 나열.
→ **효율성 :** 균등한 분포의 조건을 만족했을 때, 빠른 정렬법, 안정적인 정렬(버킷 내부도 안정 정렬 사용 시) 모든 데이터가 한 버킷으로 몰려 들어간다면, 일반 정렬과 같으므로, 최악의 경우 O(N²) 시간 복잡도. 추가 메모리 사양이 큰 편. 

> [!note]- Bucket Sort
> **버킷 정렬 구현** : 실수 데이터 정렬
>``` cpp
>void BucketSort(std::vector<float>& _vec) {  
>    int Size = static_cast<int>(_vec.size());  
>    std::vector<std::vector<float>> Buckets(Size);  
>    for (const auto& Element : _vec) {  
>        int Index = static_cast<int>(Element * Size);  
>        if (Index == Size) Index = Size - 1;    
>        // 배열 OOI 방지 (Element == 1.f)
>        Buckets[Index].push_back(Element);  
>    }  
>    
>    int Index = 0;  
>    for (auto& Bucket : Buckets) {  
>        std::sort(Bucket.begin(), Bucket.end());  
>        for (const auto& Elem : Bucket) _vec[Index++] = Elem;  
>    }  
>}
>```

> [!note]- Bucket Sort
> **버킷 정렬 구현** : 정수 데이터 정렬

>void BucketSort(std::vector<float>& _vec) {

>    
>    int MinValue = *std::min_element(_vec.begin(), _vec.end());

>    int Index = 0;  
>    for (auto& Bucket : Buckets) {  
>        std::sort(Bucket.begin(), Bucket.end());  
>        for (const auto& Elem : Bucket) _vec[Index++] = Elem;  
>    }  
>}
>```

**※ 분할 정복 방식 (Divide & Conquer)**
→ 문제를 2개(이상)로 나누어 각자 처리하는 방식. 문제를 각각 부분 문제로 분할하여, 해결하고, 필요한 경우 각각의 결과를 결합하여 하나의 결과를 만드는 '**문제 해결 방식**'. 이후에 결과를 한데 모아 최종적으로 문제를 해결해나가는 방식이다. 대부분 **재귀(Recursive) 함수 호출**을 통해 해결하는 방식이며, 반복문 형식도 존재한다.

**※ 비교 정렬과 비-비교 정렬의 차이**
→ 비교 정렬은 O(N log N)이 최선이다. O(N log N)보다 더 빠른 시간으로 정렬이 불가능 한 것이다. N개의 원소를 나열할 수 있는 경우의 수는 N! (Factorial)이다. 비교 알고리즘은 의사결정 트리 구조로 표현할 수 있는데, 밑에 예시에 설명되어 있다. Leaf노드는 최종 정렬 결과를 말하고, 높이는 최대 비교 횟수를 말한다(즉, 최악의 경우). 
```
원소 A, B, C로 나열할 수 있는 경우의 수. 3! = 6
[A, B, C], [A, C, B], [B, A, C], [B, C, A], [C, A, B], [C, B, A]

의사결정 트리(이진 트리 형태)
				  [ A < B ? ]               <- 비교 1회 (높이 1)
                 /           \
               YES            NO
              /                \
        [ B < C ? ]          [ A < C ? ]    <- 비교 2회 (높이 2)
        /         \          /         \
      YES          NO      YES          NO
     /              \      ...          ...
  [A,B,C]        [ B < A < C ? ]            <- 비교 3회 (높이 3)
                   /         \
              [A,C,B]       [C,A,B]...      <- 말단 노드 (총 N! = 6개 이상)
```

높이가 h와 Leaf노드의 수는 다음과 같이 나타낼 수 있다.
$$
2^h >= N!
$$
비교 한 번 당 2 개의 노드로 분리되므로(이진 탐색 트리) 높이별로 노드가 2배 된다고 보면 된다.
양변에 log를 적용하면, log(N!)이고, 이걸 풀어내면 스털링 근사(시간 복잡도 표현)를 적용하여 N log(N)을 만들 수 있다.
$$
log_2(N!) = log_2(1) + log_2(2) + log_2(3) + ... log_2(N); = Nlog_2(N)
$$
