'**유클리드 호제법**' 이라 불리는 알고리즘은 '**두 수의 최대공약수(GCD)**'를 효율적으로 구하는 알고리즘이다.

**※ 계산법**
1. N과 M이 있다고 했을 때(N > M), N을 M으로 나누고 나온 나머지를 Q. (몫은 정수.)
2. M을 Q로 나눈 나머지를 P , Q를 P로 나눈 나머지를 O ... 이 계산을 반복한다.
3. 진행을 하다보면, 나눴을 때, 나머지가 0이 나오는 과정에서 나눈 값이 최대공약수가 된다.

**※ 예시**

```
N = 98, M = 30
Q = N % M = 98 % 30 = 8
P = M % Q = 30 % 8 = 6
O = Q % P = 8 % 6 = 2
I = P % O = 6 % 2 = 0
※ 최대공약수 : 2
```

또한 유클리드 호제법을 통해서 '두 수의 최소공배수(LCM)' 도 구할 수 있는데, 밑 공식과 같다.
$$
	최소 공배수 = 두 수의 곱 / 최대공약수 = N * M / GCD(N, M)
$$
```
LCM(98, 30) = 98 * 30 / GCD(98, 30) = 98 * 30 / 2 = 1,470
```

### C++ 구현

``` cpp
int GCD(int N, int M) {
	if (M == 0) return N;
	return GCD(M, N % M);
}

int LCM(int N, int M) {
	return N * M / GCD(N, M);
}

#include <numeric>
std::gcd(N, M);
std::lcm(N, M);
// C++17 numeric 헤더에서 해당 함수들을 지원한다.
```
