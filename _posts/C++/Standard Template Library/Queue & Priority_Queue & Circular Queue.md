## Queue
→ **정의 :** 동일한 타입의 원소를 저장하고, First-In-First-Out (FIFO) <u>먼저 들어 간 데이터가 먼저 나오는</u> '**선입선출**' 구조의 선형 자료구조 중 하나이다. '컨테이너 어댑터' 중 하나이며, 기본 컨테이너로 STL의 deque를 사용하고 있다.

→ 예시 : 예를 들어 빨대를 생각해보자, 음료를 빨아들일 때, 처음에는 한 쪽 입구로 음료가 들어오다가, 다른 쪽 입구로 나가게 된다. 이렇게 데이터가 '한 쪽'에서 들어오면 '반대쪽'으로 나가는 구조가 Queue와 같다. 

→ **특성 :** Queue에서 데이터가 들어가는 곳을 Rear(뒤쪽), 데이터가 나오는 곳은 Front(앞쪽)이라고 한다.

---
## Method

**※ 원소 접근자**
- **ref front() / back()** - 가장 먼저 들어온 데이터 / 가장 마지막에 들어간 데이터를 조회한다.
※ **용량 확인**
- **bool empty()** - queue안에 데이터가 비어있는지 확인. (비어있다면 true)
- **size_type size()** - queue안에 데이터가 몇 개 존재하는지 확인.
※ **수정자**
- **push(const value_type& value)** - 데이터를 뒤(Rear)에 삽입.
- **emplace(Args&& value)** - 데이터를 생성하여 삽입
- **pop()** - Front에 있는 원소 삭제. (데이터를 가져오고 싶다면 front 먼저 호출 후 pop)
- **swap(queue& other)** - 다른 queue와 내부 데이터를 교환 함.

## Priority Queue

→ **정의 :** 기존에 큐는 '먼저 들어온' 데이터가 먼저 나가는 방식 이었지만, '우선 순위 큐'는 우선순위를 평가하여 데이터를 먼저 내보내는 방식의 자료구조이다. 즉, 삽입 순서보다 우선 순위가 먼저 고려되고, 우선 순위가 같은 경우엔 처리 순서를 일반적으로 보장하지 않는다.

→ **구현 :** 우선 순위 큐는 일반적으로 이진 힙(Binary Heap)을 활용하여 효율적으로 구현한다. 아직 이진 힙 문서를 작성하지 않아서 언급하자면, 개념적으로는 트리 모양의 자료구조로 시각화를 하지만, 완전 이진 트리 특성 상, 부모/자식의 위치를 인덱스로 나타낼 수 있어서 실제 구현에는 '**배열/vector**'가 사용된다. C++에서도 `std::priority_queue`는 기본적으로 `std::vector`를 내부 컨테이너로 사용하고 있다.

## Circular Queue

→ **개요 :** '순환 큐'는 배열 기반 큐의 문제점을 해결하기 위한 대체자로 나오게 된 자료구조이다. 예를 들어 최대 100개의 데이터를 저장할 수 있는 배열에 데이터를 100개 다 채웠다고 가정해보자, 거기서 90개를 제거하게 되면, 앞 쪽 (인덱스 0 - 89)의 데이터 공간은 여유가 생기고, 뒤에 (90 - 99)데이터는 채워져 있는 상태가 된다. 여기서 앞쪽에 90칸의 여유 공간이 있음에도, 데이터를 뒤로만 넣는 구조로 인해, 데이터를 더 넣을 수가 없는 문제가 생기게 된다.

→ **발전 :** 그러므로 배열의 마지막까지 데이터가 채워졌다면, 다시 처음부터(빈 곳이 있다면) 데이터를 넣어, 배열을 잘 활용할 수 있게 하는 아이디어에서 나온 것이 "순환 큐(원형 큐)"라고 한다.
