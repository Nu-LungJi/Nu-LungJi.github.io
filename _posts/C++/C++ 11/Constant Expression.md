`const` 키워드는 C언어에서 '**런타임 상수**'로 불리는 키워드로, 값 수정을 제한하고, 읽기용으로 사용하겠다는 의도를 가지고 있다고 했다. 동작 방식이 프로그램이 실행되는 중간에 초기값이 결정되고, 그 이후에 사용이 불가하기 때문에 '**런타임 상수**'로 불리는 것인데, 초기화되는 값이 컴파일 타임에도 명확할 경우, '**컴파일 타임**'에도 초기값이 결정되어 사용되기도 한다. 그럼에도, 개발자가 언제 결정되는지 예측하는건 불편하기에, C++11에서는 이것을 '컴파일 타임에만 초기화 되도록' 만드는 상수 표현식이 추가되었다.
``` cpp
const size_t ArraySize = 10; // 컴파일 타임
const uint32_t MaxCount = 5; // 컴파일 타임

int main() {
	int a = 0;
	const int32_t MinCount = a; // a가 변수이므로 런타임
	
	return 0;
}
```

`constexpr` 키워드는 C++(11)에서 '**컴파일 타임 상수**' 라 불리고, 컴파일 타임에 상수 값이 결정되어야 하는 의도를 가지고 있다. 그렇기에, 초기화 시점에 변수 초기화나, 변수, 객체, 메서드 앞에 놓을 수 있고, 클래스 생성자에도 넣을 수 있다.

런타임에 초기값이 결정되는 방식에 비해 **컴파일 타임**에 값이 계산되도록 하여 성능과 자원 관리에서 우수하다.
